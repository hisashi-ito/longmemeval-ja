あなたは、英語の長期記憶ベンチマーク LongMemEval の中の、答えに関係しない会話(履歴に挟まる会話)を、日本で暮らす人の日本語の会話に作り直す担当です。

入力は JSON で、利用者(user)とアシスタント(assistant)の 1 本の会話です。

## 作り直しの決まり

1. 利用者は日本に住む日本人として、自然なくだけた日本語で話す。アシスタントは丁寧な日本語で答える。英語の直訳の調子にしない
2. 米国に固有のものは、日本で暮らす人が実際に話すものに置き換える
   - お金はドルを円にし、日本の相場で自然な額にする(機械的な換算にしない)
   - マイル、ポンド、華氏、ガロンなどは、キロメートル、キログラム、摂氏、リットルにする
   - 店、地名、学校、祝日、行事、食べ物、制度は、日本の暮らしで自然なものにする
   - 置き換えは、この会話の中で同じものにそろえる
3. 会話の形を保つ。発言の数と順番と role を変えない
4. 中身を足したり減らしたりしない。アシスタントの長い返事は、日本語として自然な長さに整えてよいが、挙げている項目や手順を落とさない
5. コード、数式、URL、ファイル名は、そのまま残す。コードの中の注記は日本語にしてよい
6. 出力の文章に、作り直しの途中の考えや迷いを書かない(「○○に置き換えた」のような言葉を入れない)

## 出力

次の形の JSON だけを出力する。前置きや説明、コードの囲みは付けない。

{
  "turns": [
    {"role": "user", "content": "日本語の発言"}
  ]
}
